# Бот записи в автосервис

Telegram-бот, который круглосуточно записывает клиентов в автосервис и сразу уведомляет менеджера. Собран из шаблона бота приёма заявок заменой настроек в `config.py`.

## Что умеет

**Для клиента:** выбор услуги кнопками → удобные дата и время → марка автомобиля → телефон → подтверждение, номер записи и уведомление, когда запись взяли в работу. Список своих записей со статусами.

**Для менеджера:** мгновенное уведомление с кнопкой «Взять в работу», `/stats` — количество записей по услугам, `/export` — все записи в Excel.

## Стек

Python 3.12+, aiogram 3, SQLite, openpyxl, python-dotenv

## Настройка под свой сервис

Все тексты и список услуг — в `config.py` (`WELCOME`, `CHOICES`, `ASK_AMOUNT`, `ASK_PLACE`, `CONTACTS`).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

Файл `.env` рядом с `bot.py`:

```
BOT_TOKEN=токен_бота_от_BotFather
ADMIN_ID=telegram_id_менеджера
```
